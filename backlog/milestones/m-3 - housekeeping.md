## Description

Catch-all for one-off chores that belong to no feature arc — infrastructure gaps, tooling
debt, process items. Tasks here carry their own `## Why` but skip the arc-doc lifecycle step
(there is no arc doc for this milestone, by convention).

**What it buys:** a home for real, sourced work items that would otherwise either pollute a
feature arc or live only in someone's head. Current example: the Windows world-data boot
check (TASK-010), a platform-coverage gap standing since Phase 3.

**Provenance:** structural convention from the backlog-tracking standup (2026-08-18, this
repo's `AGENTS.md` "Task tracking" section) — every task gets a milestone, and Housekeeping
is the designated non-arc bucket.
